# The AI Case Files — Skills Bank

لعبة تدريب تفاعلية (عربي / English) في ملف `index.html` واحد، جاهزة للنشر على GitHub Pages.
A single-file, bilingual live training game for GitHub Pages.

## النشر على GitHub Pages / Publish
1. أنشئ Repository جديد على GitHub (مثلًا `ai-case-files`).
2. ارفع الملفات: `index.html` و `.nojekyll` (و README اختياري).
3. من **Settings → Pages**: اختر Branch = `main` و Folder = `/ (root)` ثم Save.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://<username>.github.io/<repo>/`
5. افتح الرابط، اضغط **TRAINER DASHBOARD**، وأدخل الكود **2026**.

## كيف تعمل / How it works
- **3 قضايا × 3 قرارات** (Understand the Problem → Recommend the AI Solution → Respond to the Outcome).
- بعد كل قرار: ردّ شخصية في العمل + تغذية راجعة من 3 أجزاء: What happened / Why it happened / What to consider next.
- مراجعة واحدة موجّهة بعد القرار الضعيف؛ النقاط تظهر فقط بعد تثبيت القرار؛ زيارة قضية مكتملة لا تغيّر نتيجتها.
- المدرب يرى لكل لاعب/فريق: المرحلة، القضية الحالية، تسعة مربعات للقرارات (أخضر قوي / ذهبي جزئي / أحمر يحتاج إعادة تفكير)، المراجعات، والنقاط.
- المزامنة الحية عبر **ntfy.sh** العام (بدون سيرفر خاص). كود الجلسة من 5 خانات.
- يمكن للفريق اللعب على جهاز واحد (اكتب اسم الفريق في خانة الاسم).

## النقاط / Scoring
| القرار | الحد الأقصى |
|---|---|
| 1 Understand the Problem | 30 |
| 2 Recommend the AI Solution | 40 |
| 3 Respond to the Outcome | 30 |
| **لكل قضية** | **100** |
| **المجموع** | **300** |

- درجة جزئية للتفكير المعقول وغير المكتمل.
- القرار بعد المراجعة يحصل على حتى **80%** من نقاطه.
- الترتيب: النقاط ثم عدد المراجعات الأقل.
- الشارات: Evidence Reader · Right Tool · Trust, but Verify · Growth Mindset · Case Files Master (240+ من 300).

## الحدود / Honest limits
- كود **2026** يخفي الواجهة فقط وليس حماية حقيقية؛ وسيط ntfy.sh عام وليس سريًا. استخدم أسماء مستعارة ولا تكتب بيانات سرية.
- نتائج المحاكاة داخل القضايا **مكتوبة مسبقًا** وليست نموذج ذكاء اصطناعي حيًا.
- تم اختبار اللعبة آليًا في متصفح headless مع ريلاي ntfy تجريبي (لعب كامل، العربية، الاستئناف، التخزين المحجوب، بديل polling).
- **لم يُختبر** على ntfy.sh الحقيقي ولا على أجهزة حقيقية متعددة — استخدم قائمة الفحص أدناه قبل الجلسة.

## قائمة فحص بجهازين / Two-device checklist
1. جهاز المدرب: افتح الرابط ← TRAINER DASHBOARD ← 2026 ← انسخ رابط المشاركين. تأكد من ظهور **LIVE**.
2. جهاز ثانٍ (موبايل): افتح الرابط، اكتب اسمًا، ادخل. يجب أن يظهر الاسم عند المدرب خلال ثوانٍ.
3. أكمل قرارًا واحدًا: يجب أن تتحرك المربعات/النقاط في لوحة المدرب.
4. اضغط REVEAL LEADERBOARD: يجب أن يفتح الترتيب على الموبايل.
5. جرّب زر العربية على الجهازين، ثم RESET SESSION وتأكد من الكود الجديد.
